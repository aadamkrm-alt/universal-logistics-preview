# Universal Logistics — website preview

A static preview build of three proposed regional websites, published for review only.

- `/uae/` — Universal Logistics FZE (Dubai Airport Free Zone)
- `/hk/` — Universal Freight (HK) Ltd (Kwai Chung, Hong Kong)
- `/us/` — Universal Freight & Logistics LLC (Doral, Miami)

**This is not a live site.** Every page is set to `noindex` and `robots.txt`
disallows all crawling. The enquiry forms validate but do not send.

Nothing on Universal's existing websites, hosting, DNS or email has been
changed. This repository contains only compiled output — no source code.
